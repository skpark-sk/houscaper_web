## 0. 도구 선정 배경 (강사용 메모)

| 도구 | 판단 | 이유 |
|---|---|---|
| **Cursor** | 강사 메인, 학생 서브 | 무료 한도가 금방 소진됨. 외부 API 키를 넣어도 탭 자동완성 등 핵심 기능은 자체 크레딧에 묶여 있음 |
| **VS Code + Roo Code / Cline** | **학생 메인 권장** | 애초에 BYOK(본인 키 사용) 구조라 한도 제약이 없음. MCP 연결도 GUI로 설정 가능 |
| **Claude Code** | 중급 이후 | 터미널 기반이라 MCP 설정이 초보에겐 불편 |
| **Orca (ADE)** | 이번 강의 제외 | 여러 에이전트를 깃 워크트리에 병렬로 굴리는 도구. 입문자에겐 과함 |

**핵심 전략:** 무료 API 키를 여러 개 발급받아 두고, 한도가 떨어지면 갈아끼운다. 이 과정 자체가 좋은 실습 소재.

## 1교시 (60분) — 환경 준비

### 설치 목록

| 항목 | 링크 | 비고 |
|---|---|---|
| VS Code | https://code.visualstudio.com | 필수 |
| Node.js (LTS) | https://nodejs.org | MCP 서버 실행에 필요 |
| Git | https://git-scm.com | 버전 관리 기초 |
| (선택) Cursor | https://cursor.com | 비교 시연용 |

### 강의 내용
- 바이브 코딩이란 무엇인가 — 코드를 "쓰는" 것에서 "지시하는" 것으로
- API 키 개념 잡기: 키가 무엇인지, 왜 노출되면 안 되는지
- `.env` 파일과 `.gitignore` — 키를 커밋하지 않는 습관 들이기
- VS Code 기본 조작 (터미널 열기, 폴더 열기, 확장 설치)

> ⚠️ 실습 전 반드시 강조: 발급받은 키를 화면 공유나 깃허브에 그대로 올리지 않기

## 2교시 (75분) — 무료 AI 모델 연결

### 발급받을 무료 API 키

| 제공처 | 링크 | 특징 |
|---|---|---|
| **NVIDIA Build (NIM)** | https://build.nvidia.com | 개발자 프로그램 가입만으로 무료 키 발급, 카드 불필요. DeepSeek·Llama·Qwen·Mistral·Nemotron 등 100종 이상. **OpenAI 호환** |
| **Google AI Studio (Gemini)** | https://aistudio.google.com | 무료 티어 제공, 발급 절차 간단 |
| (선택) Groq | https://console.groq.com | 속도가 빨라 시연 효과가 좋음 |

### NVIDIA NIM 핵심 포인트
- 엔드포인트: `https://integrate.api.nvidia.com/v1`
- **OpenAI 호환** → 기존 OpenAI SDK 코드에서 **base URL과 모델명 2가지만** 바꾸면 그대로 동작
- 무료 크레딧은 대략 1,000회 호출 수준 → 코딩 실습에서는 빠르게 소진됨
- 따라서 **학생 개인별로 각자 발급**받게 할 것 (강사 키 공유 금지)

### 실습 흐름
1. Roo Code (또는 Cline) 확장 설치
   - VS Code 확장 마켓플레이스에서 `Roo Code` 또는 `Cline` 검색
2. 설정에서 Provider를 **OpenAI Compatible**로 선택
3. Base URL + API Key + 모델명 입력
4. 간단한 프롬프트로 동작 확인 ("이 폴더에 hello world 웹페이지 만들어줘")
5. **키 교체 실습** — Gemini 키로 갈아끼우고 동일 작업 재실행

## 3교시 (45분) — MCP 연결 + 다음 주 준비

### MCP (Model Context Protocol)
- 개념: AI가 외부 도구·데이터에 접근하는 표준 통로
- VS Code 확장(Roo Code / Cline)에서는 설정 파일에 서버를 등록하는 방식 → **Cursor와 개념적으로 동일**
- 실습: 파일시스템 MCP 같은 기본 서버 1개 연결해보기
